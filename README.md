1. Employee Pay-Performance Analysis

Tools: Excel, Power Query, Pivot Tables

Cleaned and analyzed a 1,020-row messy employee dataset — fixed inconsistent category labels, missing values, and formatting errors. Built pivot-based analysis across department, region, performance, and remote-work status, then assembled an interactive dashboard.

Key Finding: Poor performers out-earned Excellent performers by 7–31% in 4 department-region combinations — pointing to inconsistent pay-for-performance policy.

Other findings:

Attrition status is evenly spread across departments — no red flags
Remote employees show a slightly lower Poor-performance rate (19.9%) than office employees (22.5%)
